## Code Blocks

Inline code: `const x = 1`

```javascript
function greet(name) {
  console.log(`Hello, ${name}!`)
  return name
}

greet('World')
```

```python
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```
